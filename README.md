# Home — лаунчер MiniAppHub

Стартовое мини-приложение платформы. В оболочке MiniAppHub именно оно рисует интерфейс:
рабочий стол с плитками установленных приложений, каталог и настройки.
Оболочка же остаётся пустой страницей с iframe.

## Что внутри
- **Рабочий стол** — плитки установленных приложений, запуск через `mapp.shell('openApp')`.
- **Каталог** — читает `catalog.json`, показывает карточки, ставит приложения через `mapp.apps('installApp')`.
- **Настройки** — `mapp.shell('getSettings')` / `mapp.shell('setSettings')`: адрес каталога и тема.

## Разрешения
`apps.manage` (установка приложений) и `shell.launcher` (запуск и смена лаунчера).

## Локально
```bash
npm run check
python3 -m http.server 8080 --directory mapp/public
```
Вне оболочки лаунчер запускается, но действия API возвращают `not-in-shell` — интерфейс это учитывает.
